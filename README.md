# handwriting_ocr_flask

Flask-приложение для распознавания рукописного русского текста с изображений, ручной проверки сегментации строк, исправления результата и экспорта в Word-документ.

## Возможности

- Загрузка `PNG`, `JPG` и `JPEG` с безопасными уникальными именами.
- Выделение чернил и осветление тетрадной клетки для OCR.
- Автоматическое разбиение текста на строки и ручная корректировка разделителей.
- Распознавание строк моделью TrOCR без передачи бинарной маски в модель.
- Отображение исходного и исправленного текста.
- Локальный экспорт исправленного результата в `.docx`.

## Стек

- Python 3.10+
- Flask, Werkzeug, Gunicorn
- OpenCV, Pillow, NumPy
- PyTorch, transformers
- python-docx, pyspellchecker
- HTML, CSS, JavaScript

## Модель OCR

Основная модель для современного русского рукописного текста:

```text
kazars24/trocr-base-handwritten-ru
```

Модель загружается один раз при старте процесса. При первом запуске ее файлы скачиваются из Hugging Face в локальный кеш.

Альтернативную модель можно выбрать через переменную окружения:

```powershell
$env:OCR_MODEL_NAME="cyrillic-trocr/trocr-handwritten-cyrillic"
python app.py
```

Полезные параметры:

```powershell
$env:OCR_DEBUG="0"       # скрыть диагностические изображения
$env:OCR_BATCH_SIZE="4"  # размер пакета строк для OCR
$env:OCR_NUM_BEAMS="4"   # более медленный поиск вариантов распознавания
```

## Локальная установка

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Откройте приложение:

```text
http://127.0.0.1:5000
```

## Как работает приложение

1. Flask принимает изображение и сохраняет его в `uploads/` под уникальным безопасным именем.
2. Маленькое изображение увеличивается, после чего строится маска рукописных чернил без линий клетки.
3. Для OCR готовится RGB-копия с осветленными линиями клетки; бинарная маска используется только для поиска строк.
4. Автоматическая сегментация выделяет строки и короткие фрагменты; пользователь может вручную выставить границы строк на странице результата.
5. `OCRModel` пакетно обрабатывает RGB-фрагменты выбранной моделью TrOCR.
6. Постобработка применяется только к результату, который не похож на OCR-мусор.
7. Пользователь видит исходное и исправленное распознавание, редактирует текст и выгружает `.docx` в `results/`.

## Запуск через Docker

Контейнер запускает приложение через Gunicorn. Настроен один worker, поскольку отдельный worker создает собственный экземпляр большой OCR-модели.

```powershell
Copy-Item .env.example .env
docker compose up --build
```

После запуска приложение доступно по адресу:

```text
http://127.0.0.1:5000
```

Каталоги `uploads/`, `processed/` и `results/` подключаются как локальные volumes. Кеш Hugging Face хранится в Docker volume `huggingface-cache`, поэтому модель не должна скачиваться заново при обычном перезапуске контейнера.

Первая сборка образа и первая загрузка модели могут занять значительное время. Для CUDA/GPU требуется отдельная Docker-конфигурация с совместимыми версиями PyTorch и NVIDIA Container Toolkit; текущий вариант ориентирован на CPU.

## Подготовка для GitHub

Проект содержит:

- `.gitignore`, исключающий виртуальную среду, кеши модели и пользовательские изображения.
- `.gitattributes` для согласованных переводов строк.
- `.github/workflows/ci.yml`, проверяющий синтаксис Python, базовую фильтрацию маски чернил и корректность Docker Compose без загрузки OCR-модели.
- `.gitkeep` в runtime-каталогах, чтобы пустые директории сохранялись в репозитории.

Чтобы создать новый репозиторий и отправить проект на GitHub:

```powershell
git init
git add .
git commit -m "Initial handwriting OCR Flask project"
git branch -M main
git remote add origin <repository-url>
git push -u origin main
```

Перед публикацией проверьте, что в индекс Git не попали реальные изображения или документы:

```powershell
git status --short
```

## Ограничения

- Рукописный OCR может ошибаться; текст следует проверить перед экспортом.
- Качество зависит от почерка, освещения, резкости, угла фотографии и корректной сегментации строк.
- Сложный фон и нестандартный цвет клетки могут потребовать настройки диапазонов маски.
- Словарная постобработка не восстанавливает смысл из неудачно распознанных фрагментов.
- Первая загрузка модели может занять время и требует доступа к Hugging Face.
- Базы данных и платные API не используются; все пользовательские файлы сохраняются локально.
